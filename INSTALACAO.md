# COMO INSTALAR

## Estrutura correta

Suba os arquivos mantendo exatamente esta estrutura:

Sembla/
├── README.md
├── assets/
│   └── banner.png
└── .github/
    └── workflows/
        └── snake.yml

## Forma mais fácil

1. Baixe o ZIP.
2. Extraia no computador.
3. Abra o repositório Sembla/Sembla.
4. Clique em Add file → Upload files.
5. Arraste:
   - README.md
   - pasta assets
   - pasta .github
6. Confirme em Commit changes.

## Permissão do workflow

No repositório:

Settings → Actions → General → Workflow permissions

Marque:

Read and write permissions

Depois execute:

Actions → Generate Contribution Snake → Run workflow
